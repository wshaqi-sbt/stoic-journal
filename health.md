# Health

One place for everything about the body: symptoms, medication, tests, appointments, hypotheses. Facts from entries, nothing interpreted beyond the data. The assistant does not diagnose; this file exists so a doctor's visit has a timeline.

Entry format: date, what, how I know. New entries go at the end of Timeline; corrections are added with a date, nothing is overwritten.
